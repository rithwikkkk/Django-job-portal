# Django Job Portal 🧑‍

A full-stack job portal web application built with Django where recruiters can post jobs and job seekers can apply.

---

## Features

- User authentication (Signup / Login / Logout)
- Role-based access:
  - Recruiter: Can create job listings
  - Job Seeker: Can apply for jobs
- Job listing & application system
- Admin panel for managing users, jobs, and roles
- Secure permissions using Django authentication
- Deployed on Render with live URL

---

# Tech Stack

- Backend: Django
- Database: SQLite (local), PostgreSQL (production)
- Authentication: Django Auth
- Deployment: Render
- Server: Gunicorn
- Static files: WhiteNoise

---

# Project Structure

- `accounts/` – User authentication & roles
- `jobs/` – Job listings & applications
- `templates/` – HTML templates
- `static/` – Static files

---

# Roles & Permissions

| Role       | Permissions |
|------------|-------------|
| Recruiter  | Create jobs |
| Seeker     | Apply for jobs |
